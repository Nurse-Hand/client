# NurseHand — Client

간호사 라운딩 음성을 기록하고, AI 분석 결과를 간호사가 확인·수정·확정해 인수인계로 만드는 모바일 앱입니다.

React Native + Expo 기반 프론트엔드 저장소입니다.

## 관련 저장소

| 저장소 | 역할 |
| --- | --- |
| `client` | React Native 앱 (이 저장소) |
| `server` | Node.js + NestJS API |
| `ai` | Python AI 서버 (STT, 화자 분리) |

## 기술 스택

- **React Native + TypeScript**
- **Expo SDK 54** (Expo Go 환경)
- **expo-audio** — 세션 녹음, metering 기반 발화 감지
- **expo-image-picker** — 라운딩 중 사진 첨부

## 실행 방법

```bash
npm install
npx expo start --tunnel
```

터미널에 표시되는 QR 코드를 **Expo Go** 앱으로 스캔합니다.

> `--tunnel` 없이 실행하면 로컬 IP 탐색에 실패해 `exp://127.0.0.1`로 표시되며 기기에서 접속할 수 없습니다. 같은 네트워크 환경이 확실한 경우에만 `npx expo start`를 사용하세요.

### 환경 변수

루트에 `.env` 파일을 생성합니다. (`.gitignore`에 포함되어 있어 커밋되지 않습니다)

```
EXPO_PUBLIC_API_BASE_URL=http://<서버주소>:<포트>
```

## 앱 동작 흐름

```
라운딩 시작
  → 세션 전체 녹음 (session.wav)
  → "다음 환자" 버튼으로 환자 구간 구분
  → 라운딩 종료 시 서버 업로드
  → AI 분석 (STT + 화자 분리)
  → 결과 검토 및 수정
  → 인수인계 확정
```

### 오디오 처리 방침

- 세션 전체를 하나의 `session.wav`로 녹음하고, 라운딩 종료 시 **한 번에 업로드**합니다.
- 발화 감지(metering)는 **녹음 중 UI 표시 전용**이며, 오디오를 자르거나 폐기하지 않습니다.
- 환자 구간 구분은 자동 판정이 아니라 간호사가 누르는 **"다음 환자" 버튼** 기준입니다.
- 실시간 청크 업로드는 운영 전환 시 도입 예정입니다.

## 화면 구성

| 화면 | 설명 |
| --- | --- |
| 라운딩 녹음 | 발화 감지 표시, 다음 환자 버튼, 메모·사진 첨부 |
| 빠른 기록 | 환자 선택 후 최단 경로로 음성만 기록 |
| 전체 스크립트 | 발화 원문 확인, 오타 수정, 발화 이동, 화자 변경 |
| 환자별 정리 | 녹음·메모·사진을 시간순으로 통합 표시 |
| 업무 우선순위 | 긴급도·시간민감도 지정, 업무 직접 추가 |
| AI 역질문 | 누락 항목 검증 카드 응답 |
| 인수인계 검토 | 항목별 근거 원문 펼쳐보기, 최종 확정 |

## 주요 UX 원칙

- 녹음 중, 발화 감지, 업로드 대기, AI 처리 중, 확인 필요, 실패 상태를 명확히 구분합니다.
- 목소리만으로 환자를 자동 확정하지 않습니다. 간호사의 선택·수정을 반드시 저장합니다.
- 매칭 신뢰도가 낮은 화자에만 "식별 필요"를 노출합니다. Top 3 후보를 항상 나열하지 않습니다.
- 네트워크 장애가 있어도 녹음 데이터와 작성 중 메모가 사라지지 않아야 합니다.

## 도메인 규칙

### 인수인계 섹션

```
PATIENT_STATUS   활력징후, 호흡, 의식상태
PAIN             통증
TREATMENT        투약 및 약물 외 처치
DIET             식이
ACTIVITY         활동
OBSERVATION      관찰사항, 특이사항 (보호자 문의, 낙상 위험 등)
```

### 업무 우선순위 판단 기준

1. 환자 상태 긴급도
2. 시간 제약
3. 업무 성격 (되돌릴 수 없는 일인지)
4. 선행 업무 여부
5. 이월 여부 (전 근무 인계 업무는 가중치 추가)

간호사가 긴급도·시간민감도를 직접 지정할 수 있습니다. (선택 사항)

### 라운딩 세션 상태

```
RECORDING → UPLOADED → ANALYZING → REVIEWING → COMPLETED
                                              ↘ FAILED
```
